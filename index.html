Neuen Raum aufmachen

Modus aussuchen – der Raum geht auf, der Code entsteht automatisch. Einfach laut in die Runde rufen.

1Ein Gerät öffnet den Raum (am besten ein Laptop) und ruft den Code in die Runde.
2Alle anderen öffnen dieselbe Adresse im Browser und tippen nur den Code plus ihren Namen ein.
3Der Host startet. Sein Fenster bleibt offen – er rechnet das Spiel, ein Server ist nicht im Spiel.

Lösung:

Enter = Antwort prüfen bzw. nächste Frage  ·  Esc = zurück zum Menü  ·  M = Sound  ·  N = Musik
